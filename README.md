# Paprz Lineage 📄🧱

**Paprz Lineage** is an AI-powered **Startup Epistemology & Hypothesis Thought Engine** built to test, validate, and build the real-world business **Paprz (`paprz-jkuat`)** from first principles.

Instead of building in the dark or accumulating untested assumptions, Paprz Lineage structures every business model decision, engineering pipeline, unit economics calculation, and growth loop into testable, falsifiable **5-facet building blocks**.

---

## 🧱 The 5-Facet Venture Building Block Architecture

Every hypothesis is broken down into:

1. **Hypothesis**: The exact product, market, or engineering assumption under test.
2. **Things We Know (Priors)**: All accepted baseline facts (e.g. JKUAT campus dynamics, Safaricom M-Pesa habits, photocopy shop pricing).
3. **The Experiment**: The prototype, code pipeline, A/B test, micro-survey, or cohort measurement used to test it.
4. **The Results**: Empirical findings, deduced business/engineering laws, and venture significance.
5. **Next Possible Paths**: Exactly 3 divergent strategic branches:
   - 🟢 **Validate & Deepen**: Push edge cases, unit economics, or scale boundaries.
   - 🔵 **New Horizon**: Branch into adjacent features, marketplaces, or multi-campus expansion.
   - ⚡ **Wait, how is this possible?!**: Expose an anomaly, piracy risk, or critical flaw.

## 🚀 Getting Started

### 1. Setup
```bash
cd /Users/reinhard/paprz-lineage

# Install PHP & Node dependencies
composer install
npm install

# Build frontend assets
npm run build

# Start the local development server
php artisan serve
```

### 2. Live in Browser
Open `http://localhost:8000` to interact with the **Paprz Lineage Thought Engine**.

### 3. Gemini API Integration
- Click **"Set Gemini API Key ⚙️"** in the top navigation to paste your free Google AI Studio key directly into the browser.
- Or set `GEMINI_API_KEY=` in `.env`.
- Works out of the box with offline heuristics even without a key!
